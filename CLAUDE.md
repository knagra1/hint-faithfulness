# Rules
- Work only inside this folder. Never write, install or delete anything outside it.
- Only create files listed in the layout in README.md. Ask before adding any other file.
- No new packages without asking. Never install globally.
- API keys come from environment variables only. Never print, log or commit them. Never read .env.
- Before any run that calls an API: state the number of calls and estimated cost, then wait for my OK.
- First run of anything: --limit 5.
- Commit small, one change per commit. Never push; I push.
- After any code change, show me a diff summary, not the whole file.
- The project layout is defined in README.md under "Repository layout".
